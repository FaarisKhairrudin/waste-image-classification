# Overview

## BDC Satria Data 2026

Big Data Challenge (BDC) Satria Data adalah kompetisi tahunan yang mengumpulkan talenta terbaik dalam bidang data science. Peserta mengembangkan solusi berbasis data terhadap permasalahan nyata menggunakan big data.

Permasalahan berasal dari kebutuhan bisnis, operasional, maupun strategis mitra penyelenggara (perusahaan, instansi pemerintah, lembaga penelitian, organisasi nonpemerintah, institusi pendidikan, dll). Penyelesaian kasus dilakukan melalui metode statistika, analitika data, dan machine learning menggunakan dataset yang disediakan panitia.

Tidak ada platform analitik yang ditetapkan. Setiap tim bebas menggunakan perangkat keras, perangkat lunak, serta lingkungan komputasi sendiri.

## Latar Belakang Problem

Pengelolaan sampah merupakan tantangan utama dalam pembangunan berkelanjutan. Pertumbuhan penduduk, urbanisasi, dan pola konsumsi masyarakat menyebabkan volume sampah terus bertambah. Jika tidak dikelola dengan baik, sampah menimbulkan:
- Pencemaran lingkungan
- Gangguan kesehatan masyarakat
- Kerusakan ekosistem
- Peningkatan emisi gas rumah kaca

Pemilahan sampah berdasarkan karakteristik material memungkinkan material bernilai ekonomi untuk didaur ulang, mengurangi sampah di TPA, meningkatkan efisiensi daur ulang, dan mendukung ekonomi sirkular.

Pemilahan manual masih menghadapi kendala: keterbatasan SDM, tingginya volume sampah, dan potensi kesalahan identifikasi. Teknologi AI dan computer vision dapat mengotomatisasi proses ini menggunakan model machine learning yang mengenali objek berdasarkan citra digital.
